李智慧

從一張 Hash 表到一萬臺伺服器：讀李智慧，理解後端技術的第一性原理

通讀李智慧的《大型網站技術架構》、《從0開始學大數據》、《後端技術面試38講》和《高併發架構實戰課》，我發現他反覆講的其實是同一件事：技術不是一堆孤立的知識點，而是少數幾條原理在不同尺度上的反覆出現。本文用這條主線串起軟體設計、網站架構、大數據和技術人成長，配上可執行的 Go 程式碼，也談談這些觀點在今天的侷限。
